## Defect fixed
Observed contradictory authentication UI: navigation showed Sign out while account content requested sign-in. Parallel account, wallet and navigation callers could race refresh-token rotation.

The fix shares an in-flight refresh for the same user and refresh token, while preserving logout and account-switch guards. Added/updated regression tests cover shared success, shared failure, separate users and a later token expiry.

# HIDI Mobile Premium V2

A clean React Native + TypeScript + NativeWind fashion-commerce application built on `hidi-mobile-premium-v2`.

- Five tabs: Home, Trends, Categories, Bag, Profile.
- Existing HIDI storefront APIs are reused through a typed mobile client.
- Payment, loyalty and identity features remain capability-gated when the canonical backend configuration is absent.

```bash
npm install
npm run typecheck
npm test -- --runInBand
npm run android
```
